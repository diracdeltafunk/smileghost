# Changelog

All notable changes to `smileghost` are documented here.

## 1.0.0 - 2026-07-27

- Add the `\smileghost` math operator.
- Encode the original artwork as engine-independent vector paths.
- Scale the symbol in all four TeX math styles and apply a style-aware optical lift after mathematical axis centering.
- Follow the surrounding document color.
- Add documentation, examples, regression tests, and CTAN build metadata.
